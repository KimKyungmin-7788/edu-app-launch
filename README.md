# 에듀테크앱런치 (edu-app-launch)

선생님이 만든 교육용 웹앱을 공개하기 전에 한 번에 점검하는 Claude 스킬입니다.

- 학생 정보가 밖으로 새는 경로 점검
- 폰트 라이선스 점검 (학교안심 글꼴·OFL)
- 보안 헤더 적용 (외부 보안 점검 사이트 대응)
- 개인정보처리방침·이용약관 페이지 생성 (학운위 심사 대응)
- 링크 미리보기(카카오톡 등) 설정

## 설치

**클로드 코드 / 코덱스를 쓰는 경우**
이 저장소 주소를 주고 "이 스킬 설치해 줘"라고 하면 됩니다. 업데이트도 "최신으로 업데이트해 줘"라고 하면 됩니다.

**claude.ai(웹·데스크톱 앱)를 쓰는 경우**
위쪽 초록색 `Code` 버튼 → `Download ZIP`으로 받은 뒤, 압축을 풀고 안의 `edu-app-launch` 폴더를 다시 zip으로 묶어 Claude 설정의 스킬 메뉴에서 올립니다.

## 사용

앱 폴더에서 "배포 전에 점검해 줘", "개인정보처리방침 만들어 줘", "폰트 저작권 확인해 줘"처럼 말하면 됩니다.
시작할 때 방침에 공개될 운영자 이름과 이메일을 묻습니다.

## 주의

- 개인정보처리방침·이용약관은 법률 검토를 거친 문서가 아닙니다. 학교·교육청 양식과 대조해 주세요.
- 폰트 판단은 참고용입니다. 애매하면 교육저작권지원센터 상담을 이용하세요.
