# 에듀테크앱런치 (edu-app-launch)

선생님이 만든 교육용 웹앱을 공개하기 전에 한 번에 점검하는 Claude 스킬입니다.

- 학생 정보가 밖으로 새는 경로, 화면에 드러난 API 키 점검
- 로그인·데이터베이스가 있는 앱의 보안 점검 (Supabase·Firebase·앱스스크립트)
- 법적 의무 점검 (만 14세 미만, 민감정보, AI 사용 고지, 권한, 위치 등)
- 폰트 라이선스 점검 (학교안심 글꼴·OFL)
- 보안 헤더 적용 (외부 보안 점검 사이트 대응)
- 개인정보처리방침·이용약관 페이지 생성 (학운위 심사 대응)
- 링크 미리보기(카카오톡 등) 설정

## 설치 없이 바로 점검하기

점검할 앱 폴더에서 클로드 코드나 코덱스를 열고, 아래 문장을 그대로 복사해 붙여 넣으세요.

```
배포 전 점검을 해 줘. https://github.com/KimKyungmin-7788/edu-app-launch 저장소를 이 프로젝트 폴더 밖의 임시 폴더에 내려받고, 그 안의 edu-app-launch/SKILL.md를 읽어서 지금 이 프로젝트에 그대로 적용해 줘. 문서에 나오는 templates·scripts·references 경로는 내려받은 스킬 폴더 기준이야. 점검 도구 자체는 내 프로젝트에 복사하지 마.
```

점검이 끝나면 "스킬로 저장해서 계속 쓸지"를 묻습니다. 저장하면 다음부터는 "배포 전 점검해 줘"만 말해도 됩니다.
웹 채팅(claude.ai·ChatGPT 웹)에서는 내 앱 폴더를 볼 수 없어서 이 방법을 쓸 수 없습니다.

## 설치

**클로드 코드 / 코덱스를 쓰는 경우**
아래 문장을 붙여 넣으면 됩니다.

```
https://github.com/KimKyungmin-7788/edu-app-launch 저장소의 edu-app-launch 폴더를 내 전역 스킬로 설치해 줘.
```

업데이트할 때는 이렇게 말하면 됩니다.

```
edu-app-launch 스킬을 https://github.com/KimKyungmin-7788/edu-app-launch 최신판으로 업데이트해 줘.
```

**claude.ai(웹·데스크톱 앱)를 쓰는 경우**
위쪽 초록색 `Code` 버튼 → `Download ZIP`으로 받은 뒤, 압축을 풀고 안의 `edu-app-launch` 폴더를 다시 zip으로 묶어 Claude 설정의 스킬 메뉴에서 올립니다.

## 사용

앱 폴더에서 "배포 전에 점검해 줘", "이거 배포해도 돼?", "개인정보처리방침 만들어 줘", "폰트 저작권 확인해 줘"처럼 말하면 됩니다.
앱을 파악한 표를 보여 줄 때 방침에 공개될 운영자 이름과 이메일을 묻습니다.

## 주의

- 개인정보처리방침·이용약관과 법적 점검표는 법률 검토를 거친 문서가 아닙니다. 학교·교육청 양식과 대조하고, 중요한 판단은 국가법령정보센터에서 최신 조문을 확인해 주세요.
- 폰트 판단은 참고용입니다. 애매하면 교육저작권지원센터 상담을 이용하세요.
