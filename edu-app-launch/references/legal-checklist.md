# 법적 의무 점검표

앱에 있는 기능의 행만 본다. 참고용 요약이며 조항 번호와 과태료는 법 개정으로 바뀔 수 있다.

먼저 적용 대상을 나눈다. 교사가 수업용으로 만든 비영리 앱이라도 학생 정보를 서버에 모으면 개인정보 보호 의무가 생길 수 있다. 사업자를 전제로 한 의무(사업자 정보 표시, 거래 기록 보존, 구독 전환 동의)가 교사 개인 앱에도 적용되는지는 학교·교육청에 확인할 일로 분류한다.

| 기능 | 확인할 것 | 근거 | 할 사람 |
|---|---|---|---|
| 개인정보를 받는 화면 | 방침 페이지가 있고 입력·가입 화면에서 링크된다. B형이면 위탁·국외 이전 절이 들어간다(6단계) | 개인정보보호법 제26·28조의8·30조 | 코드 |
| 장애·건강·상담 기록 | 꼭 필요한지 먼저 묻는다. 저장한다면 다른 동의와 분리한 별도 동의가 필요할 수 있다 | 같은 법 제23조(민감정보) | 사람 + 코드 |
| 만 14세 미만 학생 정보 저장·가입 | 법정대리인 동의나 학교의 동의 절차(가정통신문 등)가 있는지 확인한다 | 같은 법 제22조의2 | 사람 |
| 주민등록번호 입력칸 | 없앤다. 법령 근거 없이는 동의를 받아도 수집할 수 없다 | 같은 법 제24조의2 | 코드 |
| 탈퇴·데이터 삭제 | 삭제 표시만 바꾸지 않고 개인 식별 정보를 실제로 지우거나 익명화한다 | 같은 법 제21조 | 코드 |
| 유출 대비 | 1천 명 이상이거나 민감정보·해킹에 의한 유출이면 72시간 안에 신고해야 할 수 있다. 대응 순서 문서가 없으면 만들자고 제안한다 | 같은 법 제34조 | 사람 |
| 생성형 AI 기능 | AI를 쓴다는 사실을 화면에 알리고, AI가 만든 결과물에 AI 생성물임을 표시한다 | 인공지능기본법 제31조 | 코드 |
| 카메라·마이크·사진·위치 권한 | 필수와 선택을 나누고, 선택 권한을 거부해도 앱을 쓸 수 있게 한다 | 정보통신망법 제22조의2 | 코드 |
| 위치 정보(등하교 알림 등) | 위치기반서비스 사업 신고 대상인지 확인한다 | 위치정보법 제9조 | 사람 |
| 광고성 문자·이메일·알림 | 수신 동의는 기본 해제, 21시~8시 발송은 별도 동의가 없으면 막고, 제목에 "(광고)"와 수신 거부 방법을 넣는다 | 정보통신망법 제50조 | 코드 |
| 결제·구독 | 금액은 서버에서 검증(`server-audit.md` 4번), 거래 기록을 정해진 기간 전에 지우지 않기, 무료체험 후 유료 전환·가격 인상은 사전 동의, 사업자 정보 표시 | 전자상거래법 제6·10·13조 | 코드 + 사람 |
