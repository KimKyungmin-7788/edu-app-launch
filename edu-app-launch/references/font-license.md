# 폰트 라이선스 기준

교사가 만든 앱에서 저작권 분쟁이 가장 자주 생기는 곳이 폰트예요. 이 문서는 `scripts/check_fonts.py`
결과를 판단하고 사용자에게 설명할 때 쓰는 기준이에요. 법률 검토를 거친 문서가 아니므로 애매하면
교육저작권지원센터 상담을 권해요.

## 1. 학교안심 글꼴 (권장 기본값)

- 교육부·KERIS가 보급한 OFL(SIL Open Font License) 폰트. 대상·목적 제한 없이 상업적 이용까지 가능.
- 앱 화면, 학습지, 영상, 로고 등 **결과물에는 출처표시 의무가 없다.**
- 받을 곳: KERIS 학교안심 글꼴 배포 페이지(에듀넷·교육저작권지원센터 등 공식 경로). 다운로드 묶음에 들어 있는
  라이선스 문서(OFL.txt 등)를 버리지 말고 폰트 파일과 함께 보관한다.
- 주의: 배포 페이지의 "KERIS 공모폰트 외 폰트는 제작사 규정이 다를 수 있다"는 안내처럼, 학교안심 목록 밖의
  폰트는 각각 확인한다.

## 2. OFL 폰트를 앱에 넣을 때 지킬 것

OFL은 "폰트로 만든 결과물"과 "폰트 파일 자체"를 구분한다.

| 상황 | 해야 할 일 |
|---|---|
| 화면에 글자를 보여 주기만 함, 이미지·PDF로 저장 | 없음 (출처표시 불필요) |
| 폰트 파일(.woff2 등)을 앱 폴더에 넣어 함께 배포 (셀프 호스팅) | 같은 폴더에 **OFL.txt(저작권 고지 + 라이선스 전문)** 를 함께 둔다 |
| 깃허브 저장소에 폰트 파일 포함 | 위와 같음. 저장소에도 OFL.txt가 있어야 한다 |
| 글자 추리기(서브셋), 형식 변환, 글자 모양 수정 | 수정본이 된다. 저작권자가 정한 **예약 글꼴 이름(Reserved Font Name)** 을 수정본 이름으로 쓰지 않는다. 수정본도 OFL로만 배포 |
| 폰트 파일만 따로 판매·유료 배포 | 금지 |

예약 글꼴 이름은 OFL.txt 맨 위 저작권 줄의 `with Reserved Font Name ...` 부분에 적혀 있다. 이 줄이 없으면
예약 이름이 없는 것이다. 서브셋을 만들 때는 OFL.txt의 해당 줄을 먼저 확인하고, 예약 이름이 있으면
`@font-face`의 `font-family`는 마음대로 지어도 되지만 **파일 안의 글꼴 이름**을 바꾸거나 원본 그대로 쓰는 쪽을 택한다.
판단이 어려우면 서브셋하지 말고 원본 woff2를 쓴다.

## 3. 빌드 도구별 라이선스 파일 위치

| 폰트 위치 | 배포될 때 | 할 일 |
|---|---|---|
| 단일 HTML 앱의 `fonts/` | 폴더째 배포 | `fonts/OFL.txt` |
| Vite·React의 `public/fonts/` | 그대로 복사 | `public/fonts/OFL.txt` |
| Vite·React의 `src/` 안에서 import | 해시된 이름으로 `dist/assets/`에 복사, 라이선스 파일은 안 따라감 | `public/fonts/`로 옮기거나, `public/fonts/OFL.txt`를 따로 둔다 |
| CDN·Google Fonts로 불러옴 | 폰트 파일을 배포하지 않음 | OFL.txt 불필요. 대신 CSP 허용(`csp-recipes.md`) |

배포 후 `https://앱주소/fonts/OFL.txt`가 열리면 확실하다(`check_live.sh`에 경로를 넘기면 함께 확인).

## 4. 자주 섞여 들어오는 "무료 폰트"

| 유형 | 판단 |
|---|---|
| OFL (학교안심, 나눔 계열, Pretendard, Google Fonts 대부분) | 위 2절대로 |
| 공공누리(KOGL) 폰트 | 유형에 따라 **출처표시 의무**가 있다. 앱 하단이나 정보 화면에 출처를 적거나 OFL 폰트로 교체 |
| 기업 무료 폰트(자체 라이선스) | 제작사 약관마다 다르다. 웹 임베딩·재배포 허용 여부를 원문에서 확인. 확인 못 하면 교체 |
| 눈누 등 모음 사이트에서 받은 파일 | 모음 사이트는 배포처가 아니다. 원 제작사 페이지의 라이선스를 확인 |
| 한글·MS오피스·포토샵 등에 딸려 온 폰트 | 그 프로그램 안에서 문서 만드는 용도로만 허락된 경우가 많다. **파일을 꺼내 웹앱에 넣으면 안 된다** |
| 출처 모름 | 쓰지 않는다. 학교안심 글꼴로 교체 |

## 5. 확인 결과를 사용자에게 말하는 방식

- "통과 / 확인 필요 / 조치 필요"로 나누고, 조치 필요는 무엇을 어디에 넣으면 되는지 한 줄로 말한다.
- 사용자가 직접 확인해야 하는 것(기업 폰트 약관 등)은 Claude가 확인했다고 말하지 않는다.
- 웹에서 라이선스를 찾아 확인했다면 그 페이지 주소를 함께 보여 준다.
